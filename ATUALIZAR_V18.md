# Atualização para a versão 1.8

## O que mudou

- a avaliação acumulada agora fica salva no cadastro de cada jogador;
- o primeiro acesso reconstrói automaticamente a carreira usando todo o histórico da conta;
- o sorteio equilibrado compara a média decimal das avaliações, não apenas as estrelas;
- estreantes entram no sorteio com nota neutra 6,0;
- o placar recebeu mais destaque e mostra autores, minutos e assistências logo abaixo.

## Como atualizar no GitHub

1. Substitua os arquivos do projeto pelos arquivos desta pasta.
2. Preserve os valores configurados nos Secrets do GitHub Pages.
3. Envie as alterações para o repositório.
4. Aguarde a conclusão do workflow de publicação.

Não é necessário apagar dados nem recriar o banco. Esta versão usa as tabelas existentes e grava o acumulado dentro do cadastro protegido de cada conta.
